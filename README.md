# Cuentas Claras

Curso paso a paso de **funciones y combinatoria** para el tercer examen de Lógica y Estructuras Discretas. Todo corre en el navegador, sin servidor.

- 20 lecciones en 6 módulos: funciones, principios de conteo, permutaciones, combinaciones, problemas tipo examen y simulacro.
- Cada lección tiene tres partes: **Aprende** (explicación con calculadoras, árboles y diagramas que se mueven), **Comprueba** (quiz) y **Practica** (problemas que se corrigen solos).
- La **hoja de actividades** completa (61 problemas) con revisión y solución explicada; señala los tres errores de imprenta de la hoja original.
- Las respuestas se escriben como número o como expresión (`C(10,3)`, `26^3*10^2`, `PR(11,2,3,2)`) y se calculan con números exactos.
- La siguiente lección se abre al completar o saltar la actual. El avance se guarda en el navegador.
- `#autoprueba` revisa todas las respuestas guardadas y las compara contra conteos por fuerza bruta.

`index.html` se genera con `publicar.sh` a partir de los archivos de `fuente/`.
